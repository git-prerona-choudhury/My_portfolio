# Prerona Choudhury | Personal Portfolio

This repository contains a modern, responsive personal portfolio website for Prerona Choudhury, designed to showcase cybersecurity, web development, academic projects, and professional interests.

## Features

- Responsive and modern UI
- Smooth scrolling and animated section reveals
- Mobile-friendly navigation menu
- Hero section with a professional introduction
- About, Skills, Projects, and Contact sections
- Clean, professional styling using HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html - Main page structure
- style.css - Styling and responsive design
- script.js - Interactivity and animations
- my_pic.png - Profile image

## How to Run Locally

1. Open the project folder in your browser, or run a local server.
2. For example, using Python:

```bash
python -m http.server 8000
```

3. Open http://localhost:8000 in your browser.
